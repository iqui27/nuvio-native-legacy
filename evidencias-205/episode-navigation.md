# Modern episode row rendering

Approved baseline: `integracao/2.0.5` pinned to `b93f0fc71c446aad32e593c09b5318c36ad23b23` (the ref moves during integration). Final code: branch `agente/205-episodioslento`. Both use the same offline fixture, local artwork, ten episodes, Art background, glass enabled, 1920×1080 FBO, Portuguese, ring then zoom, forward/back traversal and 128 frames per move. Text scale is explicitly 100%, with `escalaTextoVersaoLocal 1` preventing the baseline's migration to its newer 85% default. This preference is fixture configuration, not a product change.

The strict target reports **FAIL before, rc 134**: episodes **343 rectangles / 3.779 screens**, cast **337 / 3.030**, **4,630** over-budget frames out of **5,120**, churn=0. Final reports **PASS after, rc 0**: episodes **118 / 1.429**, cast **169 / 1.610**, **0** over-budget frames out of **5,120**, churn=0. The initial performance window uses glass without frost; earlier evidence incorrectly implied it covered frost. These are host draw/fill measurements, not device timing.

Reproduction: create a detached checkout of the pinned baseline, copy the final `tests/detail_eps_shot.c` and `tests/detail_episode_perf.sh` into it, then run `NV_CC_EXTRA=-DNV_EP_BASELINE_BUILD bash tests/detail_episode_perf.sh <output-prefix>`. The compile flag omits checks for APIs introduced by this branch and allows the baseline's alpha-zero layout draws to reach the common navigation-budget assertion. It does not alter baseline production code or the budget. Final: `bash tests/detail_episode_perf.sh <output-prefix>`.

Committed `episode-{before,after}-{episodes,ring-scroll,zoom-scroll}.png` now compare the approved baseline against final code. Geometry, text placement, wrapping and focus states match at the same scale. They are not pixel-identical: thumbnail veil composition and edge antialiasing differ. Absolute RGB differences (channels >2 / maximum channel difference / mean difference on a 0–255 scale): initial row **108,646 / 62 / 0.207**, ring scroll **11,315 / 52 / 0.040**, zoom scroll **14,257 / 34 / 0.045**. The separate text regression compares approved repeated draws against composed glyphs across styles, weights and fades with a 2/255 tolerance. No claim of full-frame pixel identity.

Frost regression: the target explicitly enables frosted glass after navigation, freezes the page, invalidates the glass source and compares the real render against the same page with an intact backdrop. Before the fix, **51,348** channels differ by more than 2/255 (**rc 134**); after the fix, **0** (**rc 0**). The fix keeps the complete backdrop, including the 68 px sampling fringe, whenever glass and frost are enabled. Hole occlusion remains available without frost. `episode-{before,after}-frost.png` capture this correction; the frost-before image is the reviewed branch before the guard, not the approved baseline.
