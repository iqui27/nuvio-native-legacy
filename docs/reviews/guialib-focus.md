Guide v5 focus contract

Content, tabs and the sidebar form three layers. Up from the first content row reaches the tabs. Left from the first column opens the sidebar on the existing T21 spring. Right restores the exact content item and focus zone. Selecting a category closes the sidebar and resets the filtered content to its first row. Back closes the sidebar, then the current subview, then the guide. A second Back after closing the sidebar exits a root guide view. Every arrow either moves focus or animates an edge nudge. Rows use the DESIGN.md brighter surface; buttons use the existing accent pill.

Grid rows scroll on the existing T21 spring. Cards now window the complete live list instead of stopping after ten channels. VOD preserves its six-column page and restores the item that opened its sidebar. Sources page through all source toggles, preserving the row index. Search and Options retain their existing sheet history; their tabs participate in the same focus registry. Hidden sidebar controls are excluded from keyboard focus.
