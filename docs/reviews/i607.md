1. **Timeouts:** `src/rede.c:227` shares asynchronous fetch across `nv_http`,

2. **Response cap:** the shared reader retains at most `teto` bytes and aborts
   on reaching the cap. Counting mode retains no body; probe mode aborts after
   headers. There is no unbounded `arrayBuffer` fallback. Existing fix:
   `37b3a3819`. Regression: `limits`, with a chunked response ignoring Range.
   This bounds application retention; browser/network buffering is outside it.
3. **Content-Length escaping:** `src/rede.c:258` contains the doubled C escape;
   the test compiles the EM_JS stringification and executes the generated JS.
   Numeric values pass; `ddd`, malformed, missing, or oversized values do not.
   Existing fixes: `37b3a3819`, `d775c555f`. Regression: `probe`.
4. **Decoder failure:** `src/webp.c:251` terminates both consumers before
   publishing channel death. `largarCanalMorto` fails active direct jobs and
   advances abandoned jobs from 4 to 5; both wait and GC paths call it.
   Existing fix: `93009d304`. Regression: `decoder` (JS failure plus C GC).
5. **AVPlay cleanup:** `src/video_tizen.c:751` uses separate stop/close catches.
   Close is attempted after stop throws, errors propagate, and failed close
   remains retryable. Reopen passes through cleanup. Existing fixes:
   `93ea28a87`, `d775c555f`. Regression: `avplay`.
6. **Subtitle lifetime:** `src/addons.c:1088` copies under `legTrava` into a
   pthread-key snapshot, freed on thread exit. Valid until the same thread's
   next getter call; another thread cannot overwrite it. No compiler TLS is
   emitted for TPK40. Existing fixes: `7ab455386`, `ab3433f61`.
   Regression: `issue607_subtitle.sh`, including concurrent replacement.
7. **Fatal diagnostics:** both `tools/tizen-shell.html:377` and
   `tools/vidaa-shell.html:253` reveal and repaint the hidden panel from error
   and unhandled-rejection handlers, with recovery guidance. Existing fix:
