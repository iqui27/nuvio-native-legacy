## Cause

Baseline `src/main.c:2008` submits samples only with `app_na_home()` and at least eight decoded artworks. Settings never measures. Baseline `src/gpunivel.c:197` restores `bloqueado=1` as `decidido=1`; line 522 immediately returns forever. A saved level 0 alone does **not** stop measurement: the saved rejection flag does. The supplied log cannot establish whether that flag was present, but either gate explains no measurement-window lines. The saved file was not supplied.

Baseline `src/gpunivel.c:586` also stops at level 1 above 25 fps, even when 27–44 fps remains GPU-bound. Glass/live-color changes do not invalidate that verdict. Level 1 leaves the three-pass quarter-resolution frost chain unchanged; level 2 already uses the existing flat-glass rule. `gpun_forcar_720()` used to couple level 3/minimal effects with reduced pixels and ignore subsequent effects preferences.

The fix measures full Home and Settings, resets comparisons on scene/layout/glass/live-color changes, retries saved rejected trials on the next launch, and tries level 2 when level 1 remains GPU-bound below 45 fps. It still requires both 15% and 5 fps improvement to retain each trial. Automatic effects never select 720p. Manual Full/Light/Minimal mean levels 0/1/2, except that Mali-400/450/470 retain the established Light override to level 2. Resolution alone selects the 1280x720 internal target. Existing preference indices 0/1/2 remain; Minimal is appended at 3. A one-time per-device migration writes Minimal for legacy saved 720p + Automatic effects, preserving startup performance. Later choices remain independent, including 720p + Full; new installs mark the migration before any choice.

Light retains frost with one Kawase pass instead of two, keeping approximately the same blur variance. Minimal retains the existing no-blur rule. The owner approved the supplied PNGs on 2026-10-19 at 03:45: Settings with resolution and effects rows, and Home glass at Light with two total blur passes. No additional visual change is included in this review fix.

## Host method

`tests/gpu1080_shot.sh` uses local artwork and the actual Home/Settings draw paths, Dynamic layout, a 1920x1080 drawable, and `GL_EXT_timer_query` on Apple M4 Pro (`2.1 Metal - 91.7`). Each row averages 120 frames after 90 warmup frames. Static backdrop exercises the cache. Changing-backdrop mode advances the production frost crossfade marker every frame, forcing its normal capture/blur chain. This isolates capture/blur overhead from the same scene's cached rendering; it is not a simulated Mali GPU.

bash tests/gpu1080_shot.sh /Volumes/ExternalSSD/tmp/rev/gpu1080/before 2c98dd2e8118f6a88ef10a80a0dfabccb7f483ab
