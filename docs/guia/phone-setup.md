# Set it up on your phone, the TV follows

You don't configure add-ons on the TV. The tools below write to your **Nuvio
account**, and this app pulls everything from that account: add-ons, collections,
Home rows and stream badges. Install once on the phone, open the app on the TV,
and it's there.

## How it works

The app signs in with your Nuvio account and syncs every ~5 minutes (and at
startup, after login, and on profile switch). Nothing needs to be pushed from
the TV — the account is the single source of truth.

Phone-side tools that write to the same account:

| Tool | What it does |
|---|---|
| **AIOManager** | Manage your add-on list per profile: install, reorder, enable/disable, health checks, backup between accounts. TODO verify on test account: same-table writes, order preservation and no duplicates. |
| **Xperience** | Build visual catalogs, collections and Home layouts ("Push to Nuvio"), plus stream badge packages. TODO verify on test account: that a push lands in the same account surfaces the TV reads. |
| **Nuvio Configurator** (third-party, `nuvio.tvflix.co.uk`) | Generate `nuvio_collections.json` and AIOStreams config to import into your account. TODO verify on test account: import flow into the account. |

The TV app never writes your add-on list back — the account always wins (see
"Add-on toggles on the TV are temporary" below).

## Steps

1. **Sign in on the TV** with your Nuvio account (Settings → account). Use the
   same account in the phone tool you want to use.
2. **Configure on the phone** — install/reorder add-ons in AIOManager, push
   collections and Home in Xperience, or import a `nuvio_collections.json`
   generated by the Nuvio Configurator.
3. **Open the app on the TV.** It syncs automatically within ~5 minutes. To get
   the current list right away: **Settings → Sources and add-ons → Sync
   add-ons** (last row of the list). You'll see how many add-ons were added,
   removed or updated.

That's it. Collections and Home rows appear after the next sync; badges show on
stream lines as soon as the package is in the account.

## Add-on toggles on the TV are temporary

The add-on list is **one-way: account → TV**. You can still toggle an add-on
on or off on the TV (Settings → Sources and add-ons), but that change only
lasts on this TV until the next sync — the account's list replaces it. To make
a change permanent, do it on the phone. The same applies to the built-in
add-on list that ships with the app: the account's list replaces it on the
first sync after login.

## Subtitles: use SubMaker

Subtitle add-ons receive the exact file being played (file name, size and the
OpenSubtitles hash — the TV measures it locally when the source doesn't provide
it), so hash-matched subtitle providers work well here. We recommend
[SubMaker](https://github.com/xtremexq/StremioSubMaker): it aggregates
OpenSubtitles, SubDL, SubSource and Wyzie behind one add-on, with optional AI
translation, so one install covers the providers that would otherwise need
separate add-ons each with its own key and quota.

## Privacy

**Add-on configuration URLs are secrets.** They can embed your debrid key, an
AIOStreams password or a signed personal link. Treat them like a password:

- never post a configuration URL, UUID or token in Discord, issues or logs;
- when asking for help, describe the add-on by name and paste only the host
  (e.g. `…your-addon-host…/…`), never the full path.

## Known limits

- Up to 128 add-ons and 3 badge packages per profile.
- If the account server is unreachable, the app keeps working from the last
  good copy saved on the TV and tells you it's doing so.
- If the TV was offline for a while, use **Sync add-ons** after signing in.
